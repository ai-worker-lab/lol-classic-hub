# 클래식 노트 제품 명세

## 무엇을·왜

개인 비상업 팬 프로젝트로 운영하는 한국어 정적 정보 허브다. Riot Games Data Dragon `3.13.24/ko_KR`의 시즌 3 역사 데이터와 공식 아이콘을 출처·확인일·현행성 한계와 함께 공개한다.

## 사용자 시나리오 및 테스트

### P1 — 검색 이용자가 역사 레퍼런스를 찾는다

- 홈에서 룬, 특성(마스터리), 시즌 3 아이템, 챔피언 페이지로 이동한다.
- 각 페이지는 고유 URL·SEO 메타데이터·공식 출처·버전·로케일·확인일을 가진다.
- 챔피언 116, 아이템 205, 특성 56, 룬 296개와 공식 아이콘을 표시한다.
- 2026 League Classic의 정확한 현행 목록·수치와 동일하다고 단정하지 않는다.

### P1 — 검색 엔진이 사이트를 색인한다

- `robots.txt`, `sitemap.xml`, canonical, Open Graph, JSON-LD, `404.html`을 제공한다.

### P2 — 재방문 이용자가 빌드를 저장한다

- 이름, 챔피언, 룬·특성·아이템 메모를 서버 전송 없이 `localStorage`에 저장·삭제한다.

## 기능 요구사항

- FR-001: 순수 정적 HTML/CSS/JavaScript와 Python 3 표준 라이브러리 빌드로 동작한다.
- FR-002: GitHub Pages에 배포한다.
- FR-003: 공개 데이터 기준은 `3.13.24/ko_KR` 하나만 사용한다.
- FR-004: Riot 공식 Data Dragon JSON과 이미지 파일만 사용한다.
- FR-005: 공식 아카이브 미제공 마스터리 트리 배경·연결선은 제외한다.
- FR-006: Riot의 두 필수 고지와 역사 스냅샷 한계를 눈에 띄게 표시한다.
- FR-007: Riot 로고·공식 서비스 혼동·광고·결제·후원·유료 기능을 포함하지 않는다.
- FR-008: 계정, 게시판, 댓글, 신고, 서버 DB를 만들지 않는다.
- FR-009: Developer Portal 등록·감사를 후속 운영 작업으로 추적한다.

## 핵심 엔터티

- ReferencePage: 주제, URL, 데이터 항목, 공식 아이콘, 출처, 버전, 로케일, 확인일, 현행성 한계
- SavedBuild: 사용자 지정 이름, 챔피언, 룬·특성·아이템 메모, 수정 시각

## 성공 기준

- 공개 핵심 URL과 robots/sitemap이 HTTP 200을 반환한다.
- 정적 검증에서 개수·이미지·고지·링크·SEO 누락이 0건이다.
- GitHub Pages Action이 성공하고 main 배포 SHA가 기록된다.

## 가정과 경계

- `ai-worker-lab`은 등록 사업체·법인이 아닌 개인 프로젝트 관리용 GitHub Organization이다.
- 이 프로젝트는 무료·비상업이며 현재 수익화 계획이 없다.
- `3.13.24`는 시즌 3 역사 기준선이지 2026 League Classic의 완전한 데이터 복제본이 아니다.
- 정책 검토 문서는 법률 자문이 아니다.
