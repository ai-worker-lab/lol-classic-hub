# AIW-168 색인 가능 MVP 명세

## 무엇을·왜

공개 검색에서 롤 클래식 관련 한국어 질의에 대응하고, 검증 가능한 역사 데이터와 재방문용 클라이언트 도구를 제공하는 정적 정보 허브를 즉시 배포한다. 완전한 현행 게임 데이터보다 공개 배포, 색인 가능성, 출처 정확성을 우선한다.

## 사용자 시나리오 및 테스트

### P1 — 검색 이용자가 핵심 레퍼런스를 찾는다

- 사용자는 홈에서 룬, 특성(마스터리), 시즌3 아이템, 챔피언 페이지로 이동한다.
- 각 주제는 고유 URL, 고유 title/description, canonical, 본문을 가진다.
- 각 레퍼런스 페이지는 데이터 버전, 출처 URL, 확인일을 표시한다.
- 역사 데이터가 2026 롤 클래식 현행 데이터와 동일하다고 단정하지 않는다.

### P1 — 검색 엔진이 사이트를 색인한다

- `robots.txt`는 크롤링을 허용하고 sitemap 위치를 알린다.
- `sitemap.xml`은 핵심 공개 URL을 포함한다.
- 모든 HTML은 canonical, Open Graph, JSON-LD 구조화 데이터를 가진다.
- 존재하지 않는 경로를 위한 `404.html`이 있다.

### P2 — 재방문 이용자가 빌드를 저장한다

- 사용자는 이름, 챔피언, 룬 메모, 특성 메모, 아이템 메모를 브라우저에 저장한다.
- 저장 내용은 서버 전송 없이 `localStorage`에 유지되고 삭제할 수 있다.

## 기능 요구사항

- FR-001: 순수 정적 HTML/CSS/JavaScript로 동작해야 한다.
- FR-002: 월 고정비 0인 GitHub Pages에 배포해야 한다.
- FR-003: 홈, 룬, 특성, 아이템, 챔피언, 빌더, 404를 제공해야 한다.
- FR-004: Data Dragon `3.15.5` 한국어 JSON은 출처 후보 URL과 확인일만 표시하고, 정책 게이트 해제 전에는 게임 데이터·에셋을 공개하지 않아야 한다.
- FR-005: `3.15.5` 데이터는 역사 참고이며 2026 현행 클래식 반영 여부는 `확인 중`으로 표시해야 한다.
- FR-006: 계정, 게시판, 댓글, 신고 기능을 만들지 않는다.
- FR-007: Riot 로고, 챔피언 원화, Data Dragon 아이콘, 공식 UI를 사용하지 않는다.
- FR-008: README에 실행, 배포, 데이터 갱신, D+14/D+30 운영 기준을 기록해야 한다.
- FR-009: PC와 모바일 뷰포트에서 내비게이션, 레퍼런스 목록, 빌더가 가로 스크롤 없이 사용할 수 있어야 한다.

## 핵심 엔터티

- ReferencePage: 주제, URL, SEO 메타데이터, 데이터 항목, 출처, 확인일, 검증 상태
- SavedBuild: 사용자 지정 이름, 챔피언, 룬/특성/아이템 메모, 수정 시각

## 성공 기준

- 공개 URL에서 홈과 5개 핵심 경로가 HTTP 200을 반환한다.
- 공개 `robots.txt`와 `sitemap.xml`이 HTTP 200을 반환한다.
- 정적 검증 스크립트에서 필수 메타데이터·출처·링크 누락이 0건이다.
- 브라우저 자동 검증에서 빌드 저장·재로드·삭제가 동작한다.
- 커밋과 origin push, GitHub Pages 배포가 완료된다.

## 가정과 경계

- Paperclip AIW-168 이슈 본문과 상위 AIW-166 보드 결정을 제품 요구사항의 SSoT로 사용한다.
- 상위 AIW-166의 2026-08-02 Riot IP 출시 게이트에 따라 중립 정적 셸만 먼저 배포하고 게임 데이터·에셋 공개와 광고 신청은 중단한다.
- Data Dragon `3.15.5`는 공식 CDN에서 접근 가능한 역사 스냅샷이지만, 시즌3 또는 신규 롤 클래식의 실제 구성과 동일하다는 근거로 사용하지 않는다.
