# AIW-183 공개 게이트 재검증 계획

## 요약

기존 공개 중립 셸과 AIW-173의 Data Dragon 보관 브랜치를 변경 없이 검증한다. 공식 정책이 Data Dragon을 허용 자산으로 열거하는지와 동시에 사업·법인 관여 프로젝트를 제한하는지 확인한다. 모든 공개 전제조건이 충족될 때만 에셋 통합·Pages 재배포로 진행한다.

## 기술 맥락

- 사이트 기준 브랜치: `AIW-168-48-mvp`
- 에셋 기준 브랜치: `AIW-173-3-data-dragon`
- 데이터 버전/로케일: `3.13.24` / `en_US`
- 배포 대상: GitHub Pages
- 공식 정책 출처: Riot Games Legal, Riot Developer General Policies, League of Legends Data Dragon 문서

## Constitution Check

- Spec-first: `docs/aiw-183-spec.md`를 먼저 작성한다.
- 출처 우선: 공식 Riot URL과 실제 SHA-256만 근거로 사용한다.
- 안전한 기본값: 정책 충돌 또는 운영 주체 불명확 시 공개 게이트를 유지한다.
- 추적성: 판정과 해제 조건을 `docs/policy-gate.md` 및 검증 보고서에 연결한다.
- 최소 변경: 공개 불가 판정이면 사이트 코드·에셋·배포 설정을 변경하지 않는다.

## 검증 단계

1. 공식 버전 목록과 데이터셋 4종 접근성을 확인한다.
2. 매니페스트 전체 677개 참조(고유 URL 451개)의 원격 SHA-256과 로컬 파일을 대조한다.
3. 공식 정책 원문에서 허용 자산, 필수 고지, 등록 의무, 사업·법인 제한을 추출한다.
4. 시즌3 역사 자료 적합성과 2026 현행 일치 여부를 분리해 판정한다.
5. 공개 전제조건이 충족되면 통합·배포하고, 아니면 차단 근거·해제 절차를 기록한다.

## 복잡성 추적

- 같은 이미지 URL을 여러 레코드가 참조해 매니페스트 에셋 항목은 673개지만 고유 이미지 파일은 447개다.
- 데이터 무결성 통과는 저작권·정책상 공개 허용을 자동으로 의미하지 않는다.
- Developer Portal 등록은 계정 소유자의 인증이 필요한 외부 행위이므로 에이전트가 대신 완료하지 않는다.
