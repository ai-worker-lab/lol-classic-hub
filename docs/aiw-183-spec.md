# AIW-183 Data Dragon 공개 재개 명세

## 무엇을·왜

개인 비상업 팬 프로젝트인 `클래식 노트`에 Riot 공식 Data Dragon의 시즌 3 역사 데이터와 아이콘을 공개한다. `3.13.24/en_US` 에셋과 기존 MVP의 `3.15.5/ko_KR` 후보 불일치를 제거하고, 공개 사이트의 단일 기준을 `3.13.24/ko_KR`로 고정한다.

## 사용자 시나리오 및 테스트

### P1 — 방문자가 출처가 분명한 역사 데이터를 본다

- 챔피언·아이템·룬·특성 목록에 이름과 공식 Data Dragon 아이콘이 노출된다.
- 모든 데이터 페이지에 버전 `3.13.24`, 로케일 `ko_KR`, 공식 출처, 확인일이 표시된다.
- 이 자료가 2026 League Classic의 정확한 현행 목록·수치가 아니라 시즌 3 역사 스냅샷임을 눈에 띄게 밝힌다.

### P1 — 운영자가 정책 조건을 확인한다

- 운영 주체를 등록 사업체·법인이 아닌 개인 비상업 프로젝트로 기록한다.
- Riot `Legal Jibber Jabber`의 개인 비상업 팬 프로젝트 허용과 고지 조건, Developer General Policies의 Data Dragon 허용 자산·등록 의무·필수 고지를 기록한다.
- Riot 로고·공식 서비스 혼동·광고·결제·후원·유료 기능을 포함하지 않는다.
- Developer Portal 제품 등록·감사는 공개와 병행하는 운영 후속 작업으로 추적한다.

### P1 — 운영자가 데이터 무결성과 실제 공개를 검증한다

- Data Dragon `3.13.24` 공식 버전 존재와 `ko_KR` 4종 JSON 접근성을 검증한다.
- 배포된 데이터 수, 이미지 참조, 로컬 파일 존재를 자동 검증한다.
- GitHub Pages의 핵심 URL, 고지문, 버전, 실제 이미지 응답을 확인한다.

## 기능 요구사항

- FR-001: 공개 사이트는 `3.13.24/ko_KR`만 데이터 기준으로 사용해야 한다.
- FR-002: 챔피언 116, 아이템 205, 룬 296, 특성 56개를 공식 JSON에서 읽어야 한다.
- FR-003: 각 항목은 공식 `3.13.24` 이미지 파일을 참조해야 한다.
- FR-004: 마스터리 트리 배경·연결선처럼 공식 아카이브가 제공하지 않는 자산은 제외해야 한다.
- FR-005: Riot의 두 필수 고지, Data Dragon 출처·버전·로케일·확인일·현행성 한계를 눈에 띄게 표시해야 한다.
- FR-006: Riot 로고·공식 서비스 혼동·수익화 기능을 포함하지 않아야 한다.
- FR-007: Developer Portal 등록·감사를 후속 운영 작업으로 추적해야 한다.

## 성공 기준

- 로컬 빌드와 검증 스크립트가 오류 0으로 끝난다.
- 데이터 매니페스트에 `116/205/56/296` 개수가 기록된다.
- 공개 페이지 네 곳에 실제 데이터와 이미지가 노출된다.
- GitHub Pages 배포 Action이 성공하고 공개 URL이 HTTP 200을 반환한다.
- 운영 주체·정책 판정·데이터 버전 결정·배포 SHA가 문서와 이슈에 남는다.

## 가정과 경계

- 사용자 확인에 따라 `ai-worker-lab`은 개인 비상업 프로젝트를 정리하는 GitHub Organization이며 등록 사업체·법인이 아니다.
- `3.13.24`는 시즌 3 역사 기준선이다. Riot의 2026 League Classic은 단일 역사 패치의 완전 복제가 아니므로 현행 동일성을 주장하지 않는다.
- 이 문서는 법률 자문이 아니라 Riot 공식 정책에 대한 운영 사전 검토다.
