# AIW-185 기능 명세 — 아이템 조합·업그레이드 트리

## User Scenarios & Testing

### P1 — 아이템 조합 탐색
사용자는 아이템 목록·검색에서 아이템을 선택하고 공유 가능한 상세 URL에서 하위 재료, 현재 아이템, 상위 업그레이드를 분리해 본다.

- Acceptance: 205개 아이템에 `/season3-items/{id}/` URL이 생성된다.
- Acceptance: `from`과 `into`의 비어 있지 않은 관계가 Data Dragon 그대로 렌더링된다.
- Acceptance: 관계 노드를 선택하면 그 아이템의 상세 URL로 이동한다.
- Acceptance: 직접 URL 접근과 브라우저 뒤로 가기가 정적 페이지에서 동작한다.

### P2 — 비용과 수량 판단
사용자는 각 노드의 아이콘, 한글 이름, ID, 총 가격, 조합 비용, 구매 가능 여부를 확인한다.

- Acceptance: 같은 형제 재료 ID가 반복되면 단일 노드와 `×N`으로 표시한다.
- Acceptance: `gold.total`, `gold.base`, `purchasable`을 추정 없이 표시한다.

### P3 — 특수·비정상 데이터 이해
사용자는 관계가 없는 경우와 맵 제한·구매 불가 데이터를 명확히 이해한다.

- Acceptance: 하위 관계가 없으면 “기본 아이템”, 상위 관계가 없으면 “상위 업그레이드 없음”을 표시한다.
- Acceptance: `maps` 데이터의 제한과 `purchasable=false`를 배지로 표시한다.
- Acceptance: 누락 참조, 순환, 최대 깊이를 안전한 상태 문구로 종료한다.

## Edge Cases

- 동일 재료가 여러 번 등장한다.
- 참조 대상 ID가 데이터에 없다.
- 향후 데이터에 순환이 생긴다.
- 최대 깊이 8을 초과한다.
- `gold`, `maps`, `purchasable` 필드가 없거나 비어 있다.
- 모바일에서 세 열이 세로 단계로 재배치된다.

## Requirements

- FR-001: Data Dragon `3.13.24/ko_KR item.json`의 `from`·`into`만 관계 SSoT로 사용한다.
- FR-002: 205개 정적 상세 페이지와 목록의 의미 있는 링크를 생성한다.
- FR-003: 하위 재료·현재 아이템·상위 업그레이드를 연결선 없이도 구분되는 3단 구조로 표시한다.
- FR-004: 형제 관계를 ID별로 집계해 수량을 표시한다.
- FR-005: 노드에 아이콘·이름·ID·총 가격·조합 비용·구매 가능 여부·데이터 기반 배지를 표시한다.
- FR-006: 검색은 점진적 JavaScript로 제공하되 목록·상세 핵심 정보는 JavaScript 없이 접근 가능해야 한다.
- FR-007: 방문 집합과 최대 깊이 8로 재귀를 제한한다.
- FR-008: 사이트맵·내부 링크 검증에 상세 URL을 포함한다.
- FR-009: 기존 고지, 출처, 버전, 비수익화 경계를 유지한다.

## Key Entities

- Item: Data Dragon ID와 아이템 레코드.
- Relation: `from` 또는 `into`의 참조 ID와 형제 내 수량.
- Tree Node: Item 또는 누락·순환·깊이 제한 상태.

## Success Criteria

- SC-001: 상세 페이지 205개, 깨진 상세 링크 0개.
- SC-002: 비어 있지 않은 `from` 보유 158개, `into` 보유 65개와 참조 279/267개 검증.
- SC-003: 누락 참조와 순환 0개이며 방어 회귀 테스트가 통과한다.
- SC-004: 조화의 성배(3028)의 요정의 부적(1004)이 `×2`로 표시된다.
- SC-005: 정적 빌드·검증·GitHub Actions가 성공하고 공개 상세 URL이 HTTP 200이다.

## Assumptions

- Data Dragon의 `maps` 키는 맵별 사용 가능 여부만 표시하며 맵 이름을 추정하지 않고 ID로 표기한다.
- 트리는 각 방향 최대 깊이 8까지 렌더링한다.
